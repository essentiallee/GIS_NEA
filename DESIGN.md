## Open from VS Code

Click the link above, or choose **Terminal → Run Task → Open GIS_Final in Figma**.

## Working between design and code

Use Figma to develop and review layout, typography, and visual hierarchy. Implement agreed changes in the HTML, CSS, and map configuration, then preview the website locally.

This reference link does not automatically synchronize Figma edits with website code. To implement a particular screen, select its frame in Figma and provide that frame's link.

## Implemented screen

[Desktop frame 1:2](https://www.figma.com/design/PaYGMeDTtFoZWBah2SaZfV/GIS_Final?node-id=1-2) was implemented on November 17, 2026. The 1728 x 1117 reference defines two panels (843/804 px wide), a 26 px gap, 40 px corners, #d5d5d5 outlines, rgba(233,233,233,0.1) fill, 30 px regular Space Mono title, and a 14 px source footer. At narrower desktop widths, the panel widths adapt proportionally; on small screens they stack.


## November 19: white canvas and floating cards
