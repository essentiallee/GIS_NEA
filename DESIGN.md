## Open from VS Code

Click the link above, or choose **Terminal → Run Task → Open GIS_Final in Figma**.

## Working between design and code

Use Figma to develop and review layout, typography, and visual hierarchy. Implement agreed changes in the HTML, CSS, and map configuration, then preview the website locally.

This reference link does not automatically synchronize Figma edits with website code. To implement a particular screen, select its frame in Figma and provide that frame's link.

## Implemented screen

[Desktop frame 1:2](https://www.figma.com/design/PaYGMeDTtFoZWBah2SaZfV/GIS_Final?node-id=1-2) was implemented on November 17, 2026. At narrower desktop widths, the panel widths adapt proportionally; on small screens they stack.
